HYPERCAT WEBSITE
================

This is a complete static landing page based on the approved Hypercat mockup.

FILES
-----
index.html      Main page
styles.css      Design + responsive layout
script.js       Mobile menu, scroll reveals, nav highlighting
assets/         Your supplied Hypercat artwork

HOW TO USE
----------
1. Open index.html locally to preview.
2. Upload the whole folder to GitHub Pages, Vercel, Netlify, STRATO, etc.
3. In script.js replace:
   HYPERCAT_LINKS.buy
   HYPERCAT_LINKS.x
   HYPERCAT_LINKS.telegram
   HYPERCAT_LINKS.discord
   with your real official links.

IMPORTANT
---------
The chart, price, holder count and tokenomics shown are visual/demo content based on the design mockup.
Replace them with your real project data before publishing as factual information.
